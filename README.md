# Sebastijan Babić, portfolio

Personal portfolio: mathematical statistics and software engineering.

Vite, React, TypeScript, Tailwind, shadcn/ui. Content lives in `src/data/`.

## Development

```sh
bun install
bun run dev
```

## Deploy

GitHub Pages via `.github/workflows/deploy.yml`, on every push to `main`. Live at https://heffri.github.io/sebastijanb/
